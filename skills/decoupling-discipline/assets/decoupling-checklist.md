# 编码前自检清单 (Decoupling Checklist)

> 使用方式：在写任何代码（或让 AI 写代码）之前，逐项回答以下问题。一项不明确也不要动手。
> 将此清单复制到你的功能目录下，每个模块填写一份。

---

## 一、模块边界

### 1.1 归属决策

- [ ] 这段代码应该放在现有哪个模块中？
  - 所属模块：`___________`
- [ ] 还是需要创建新模块？
  - 新模块名称：`___________`

### 1.2 职责声明（戒律二检查）

- [ ] 用一句话描述该模块的职责（不含"和""以及""同时"）：
  > `____________________________________________`
- [ ] 这句话是否精确、不含糊？
- [ ] 模块名称是否准确描述了以上职责？

### 1.3 接口契约（戒律一检查）

- [ ] 该模块对外暴露的接口是什么？
  - 输入参数：`___________`
  - 返回值：`___________`
  - 可能抛出的错误类型：`___________`
- [ ] 接口是否隐藏了所有实现细节（数据库类型、第三方库名）？
- [ ] 调用方能否在不修改的情况下替换该模块的实现？

### 1.4 依赖关系

- [ ] 该模块依赖哪些现有模块？
  - 依赖列表：
    1. `___________`
    2. `___________`
    3. `___________`
- [ ] 是否存在反向依赖？（被依赖方不能反过来依赖依赖方）
- [ ] 是否存在循环依赖？（A → B → A 的链条）
- [ ] 依赖是否都基于接口而非实现？

---

## 二、耦合风险评估

### 2.1 结构耦合

- [ ] 修改这个模块时，是否需要同步修改其他模块？
  - 需要同步修改的模块列表：
    1. `___________`
    2. `___________`
  - 如果需要改 3+ 个模块 → **边界设计有问题，重新划分**
- [ ] 其他模块修改时，这个模块是否会跟着崩？
  - 被谁影响：`___________`

### 2.2 状态耦合（戒律五检查）

- [ ] 该模块是否使用了全局/模块级可变状态？
  - 变量名：`___________`
  - 能否改为参数传递？是 / 否
  - 能否改为不可变？是 / 否
- [ ] 该模块是否与其他模块共享可变状态？
  - 共享的变量：`___________`
  - **存在共享就是耦合，必须消除**

### 2.3 继承耦合（戒律三检查）

- [ ] 是否使用了继承？
  - 继承层级：`___` 层（超过 2 层 → 改组合）
- [ ] 子类是否覆写了父类 50% 以上的方法？是 → 继承不恰当
- [ ] 父类的改动是否会级联影响子类？是 → 改组合

### 2.4 接口成本评估

- [ ] 拆分后的接口维护成本是否低于耦合成本？
  - 耦合成本估算：当前模块改一行会影响 _________ 个其他地方
  - 接口成本估算：需要定义和维护 _________ 个新接口
  - 接口成本 < 耦合成本 → 值得拆
  - 接口成本 > 耦合成本 → 不拆（罕见，需确认计算）

## 三、AI 编码准备

> 如果是人类编码，以下可跳过。如果是 AI 编码，以下每一项都必须确认。

### 3.1 架构边界已定义

- [ ] 模块边界图或列表已明确？
- [ ] 每个模块的接口契约已写入 [interface-contract.md](interface-contract.md) 模板？
- [ ] 依赖方向已规划（无循环依赖）？

### 3.2 当前实现范围

- [ ] 当前要生成的模块**只有一个**？（禁止一次生成多个）
- [ ] 该模块的接口契约已经**书面化**且无歧义？
- [ ] 该模块的测试用例已经预先定义好？

### 3.3 上一次模块状态

- [ ] 上一个模块的测试是否**全部通过**？（未通过 → 禁止开始新模块）
- [ ] 已有模块的回归测试是否**全部通过**？（有失败 → 先修复再继续）
- [ ] 上一个模块的代码是否已经提交？（未提交 → 先提交或确认可继续）

---

## 四、最终确认

回答以下三个问题，全部为"是"才能开始编码：

1. [ ] 我知道这段代码属于哪个模块，以及为什么？
2. [ ] 这个模块的边界清晰——我知道什么归它管，什么不归它管？
3. [ ] 我（或 AI）一次只实现这一个模块，不跨模块生成代码？

---

> **警告**：跳过此清单直接编码的后果——你正在向未来借技术债。今天的每一行快捷代码，都会在某个深夜以离谱的 bug 形式回来找你。
