# 小说大纲创作技能

本技能帮助用户进行小说大纲的创作与规划，提供从粗纲到细纲的完整指导。

## 一、大纲概述

小说大纲是整个小说的纲要，是写作前期的故事构造和整体把握。

### 大纲分类
- **粗纲**：一句话描述，如"莫北黑了罗凯泽的账号，匿名威胁他离开俞秀筠"
- **细纲**：详细描述情节过程，包含渴望、障碍、冲突、行动、情感、爽点等要素

## 二、细纲编写模板

### 章节细纲要素

| 要素 | 说明 |
|------|------|
| 渴望 | 主角的目标或动机 |
| 障碍 | 阻碍主角达成目标的因素 |
| 冲突 | 主角与对立面的矛盾 |
| 暗中 | 暗线进行的行动 |
| 明面 | 明线进行的行动 |
| 行动 | 具体的情节发展步骤 |
| 情感 | 角色的情感状态 |
| 展示 | 通过情节展示的角色特质 |
| 爽点 | 让读者感到满足的关键点 |

## 三、完整大纲结构

### 1. 题材定位
明确小说类型（玄幻/都市/历史等），避免写作过程中跑偏。

### 2. 特色与卖点
- 新奇的世界观设定
- 主角逆袭的爽感
- 角色间的爱恨情仇
- 独特的金手指设定

### 3. 读者群定位
明确目标读者群体，调整写作风格以迎合读者。

### 4. 相关设定

#### 环境设定
故事发生的背景环境，包括地点、时代、社会环境等。

#### 等级设定
主角成长体系，如：
- 玄幻：斗之气→斗者→斗师→大斗师→斗灵→斗王→斗皇→斗宗→斗尊→斗圣→斗帝
- 武侠：明劲→暗劲→化劲→丹劲→罡劲→打破虚空
- 都市：金钱、地位、权力等级

#### 人物设定
- 主角：性格、身世、目标、金手指
- 配角：与主角的关系、性格特征、作用
- 反派：对立原因、实力设定

#### 金手指设定
先天或后天赋予主角的特殊能力或资源。

### 5. 故事主线
开局→矛盾发展→转折→高潮→结束→新地图开局（如需换地图）

### 6. 分卷大纲
每卷包含：字数、地点、人物、成长进度等概述。

## 四、细纲三大板块

### 情节板块
- **情节名称 + 作用**：明确每个情节的功能
- **基本信息**：时间、地点、关键人物、视角、环境
- **预计字数**：反映情节重要程度

### 目的板块
- **梗概**：主角主要目的
- **拆解**：具体行动步骤
- **后续**：为下一情节留钩子

### 冲突板块
- **梗概**：阻碍主角的事
- **拆解**：具体冲突步骤
- **后续**：为后续行动留钩子

## 五、使用指南

1. **新人建议**：可从简单粗纲开始，逐步完善
2. **即兴创作者**：大纲可适当简化，保留创作空间
3. **规划型作者**：建议完成详细大纲后再动笔

## 六、注意事项

- 大纲主要服务于自己，不必过于纠结形式
- 投稿时编辑更看重开篇三万字
- 大纲可根据创作过程动态调整
- 避免因过度追求大纲完美而耽误创作
