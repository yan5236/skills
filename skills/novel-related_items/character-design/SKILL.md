# 小说人物设定技能

本技能基于小说三要素中的人物要素，提供系统化的人物设定指导。

## 一、角色功能定位

### 1.1 主角：功能性大于完美性
- 人设不能太完美，不完美才能引出更多故事线
- 功能性要显著：金手指、信息差运用能力、特殊技能等
- 可设置性格缺陷：过度自信、躁郁症、社恐等

### 1.2 配角：记忆点大于完整性
- 定位为工具人，给主角制定矛盾或解决矛盾
- 抓取最独特的记忆点，不需面面俱到
- 例：嗜甜如命的暗卫、结巴的毒医

### 1.3 反派：破坏力大于邪恶值
- 必须在实际上给主角带来压力
- 例：修为高超但被心魔控制的大能

## 二、人物基础模型

```
【人物档案】
姓名：__________
年龄：__________（可标注成长跨度）
身份：__________（表面身份/隐藏身份）
外貌：__________（动态描写优先）
记忆锚点：__________（标志性特征）
```

### 外在形象塑造
- 使用动态描写代替静态描写
- 参考范例：王熙凤出场（未见其人先闻其声）

### 内在形象构建
- **关心对象**：人物最在意的人或事
- **害怕对象**：人物最深层的恐惧
- **动机**：驱动人物行动的核心原因
- **动力层次**：
  1. 生存安全保障
  2. 爱和归属
  3. 自尊和他人的尊重
  4. 认知和理解的需求
  5. 审美自我的体现

## 三、背景设定

### 3.1 家庭背景
- 家庭是性格形成的根本
- 冷漠的人→没感受过爱
- 天真的人→被保护得很好
- 复杂的家庭环境→更多剧情延伸

### 3.2 情感联系
- 亲情线、友情线、爱情线
- 每条线都能支撑剧情走向

### 3.3 双重身份设定
- 隐藏身份带来期待值
- 例：面馆老板/风水大师

### 3.4 社会背景
- 社会地位
- 教育水平
- 过往经历
- 决定语言和行为模式

## 四、性格立体化

### 4.1 核心矛盾点设置

| 矛盾类型 | 说明 | 示例 |
|---------|------|------|
| 价值观冲突 | 新旧身份观念碰撞 | 医学生穿越成用毒世家继承人 |
| 行为模式冲突 | 性格与处境不符 | 极度社恐被迫成为团队领袖 |
| 认知冲突 | 自我认知与现实背离 | 救赎文男主坚信自己不值得被爱 |

### 4.2 特定行为反应
- **本能反应**：被背叛时立即拔剑
- **理性反应**：强压怒火分析利弊
- **隐藏反应**：指尖掐入掌心渗血

### 4.3 语言动作设计
- 大家闺秀：洗手擦三条帕子、步子大小一致、笑不露齿
- 底层混混：切口黑话、随地吐唾沫、翘二郎腿

## 五、成长规划

### 5.1 能力成长可视化
- 修仙文：灵气雾状→金丹凝实
- 都市文：二手电动车→定制超跑
- 服装变化：帆布鞋体恤→西装革履

### 5.2 黑化/觉醒触发点
**关键事件节点**（至少3个）：
- 亲友背叛
- 力量反噬
- 信仰崩塌

**隐藏开关**（预留1个）：
- 童年记忆封印
- 血脉诅咒

## 六、社会关系网

### 6.1 血缘关系
- 天然带来麻烦或帮助
- 例：父亲是赌徒→孩子被催债

### 6.2 强联系建立方式
- **利益捆绑**：主角掌握反派必需资源
- **信息差掌控**：配角知晓主角弱点
- **情感负债**：男二曾导致女主家族蒙冤

## 七、记忆点强化

### 7.1 标志性行为
- **语言特征**：特定场景台词
- **动作标签**：转笔必失误、紧张啃衣角
- **时间标签**：每逢月圆夜功力尽失

### 7.2 反差设定
- 反差萌增强记忆点
- 例：凶悍外表+温柔内心

## 八、冲突设计公式

**冲突 = 渴望 + 阻碍**

为重要人物设定：
1. 明确的渴望（知识/财富/享乐/权力等）
2. 阻碍其达成渴望的因素
3. 人物的努力方向和潜意识愿景

## 使用建议

1. **先定位后塑造**：明确角色功能再设计细节
2. **矛盾驱动剧情**：性格矛盾是故事推进的引擎
3. **记忆点优先**：读者记住人物才能记住故事
4. **成长可视化**：让读者看见人物的变化
5. **关系网编织**：人物关系越紧密，剧情越紧凑
